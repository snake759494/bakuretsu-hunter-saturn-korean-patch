# 폭렬헌터 번역 지침

모든 명령은 저장소 폴더에서 실행합니다.

## 파일
- 장면 대사: `tr/<장>_<장면>.txt` = 한 줄에 `번호<TAB>한국어`. 번호는 장면 안 메시지 순서이며, 원문은 추출한 `disc/PRG/MEN<장면>.BIN`의 같은 번호 메시지입니다.
- `//`로 시작하는 줄은 주석입니다. UTF-8로 저장합니다.
- `ko/*.json`은 `tools/wrap.py`가 만드는 결과이므로 직접 고치지 않습니다.

## 반드시 지킬 형식
1. 대화창은 한 줄 15칸, 한 페이지 3줄입니다. `wrap.py`가 단어 단위로 자동 줄바꿈하고 3줄마다 페이지를 나눕니다.
2. `▼`는 페이지 넘김(버튼 대기), `/`는 강제 줄바꿈입니다.
3. `「`로 시작하는 대사는 둘째 줄부터 전각 공백으로 들여 씁니다. 원문이 대사면 번역도 `「…」`로 감쌉니다.
4. `\`로 시작하는 메시지는 줄바꿈 없이 그대로 씁니다(커맨드 `\보기`·`\조사`·`\말하기` 등).
5. `⟨번호⟩`는 원본 장면 글꼴의 글리프를 그대로 쓰는 자리입니다(`glyphs.bin`의 번호). `♥` 같은 기호는 나눔스퀘어 네오로 그려집니다.
6. 선택지 메시지는 짧게(한 줄) 씁니다.

## 번역 원칙
- **기계 번역 금지.** 문맥을 보고 직접, 자연스러운 한국어로 번역한다.
- 말투는 원문의 반말·존댓말을 따르고, 캐릭터마다 장면이 바뀌어도 같은 말투를 유지한다.
- 이름: キャロット 캐롯, ショコラ 쇼콜라, ティラ 티라, ガトー 가토, マロン 마론, ドーター 도터, ビッグ・マム 빅 맘, ソーサラー 소서러, パースナー 퍼스너.
- 말장난·성적 농담은 수위를 유지하며 한국어로 통하게 의역한다.
- 칸이 좁으면 뜻을 지키며 줄인다.
